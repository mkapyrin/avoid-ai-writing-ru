# Расширения: нишевые словари и тезаурусы

Базовый `SKILL.md` покрывает штампы, общие для всех тем. В каждой нише есть свои: в постах психологов, медицинских статьях, маркетинговых рассылках, текстах про криптовалюты. Есть и обратная проблема: термин, законный в нише, базовый словарь может пометить. «Экосистема» у биолога и «трансформация» у математика AI-маркерами не являются.

Расширение решает обе задачи. Это markdown-файл с frontmatter и таблицами. Скилл подключает его, когда текст подходит по теме.

## Где хранить

- **В этой папке**, если расширение общего назначения и вы готовы его поддерживать: присылайте PR.
- **В своём репозитории**, если словарь узкий, коммерческий или живёт по своему графику. Пользователь подключает его, назвав путь в запросе или в инструкциях проекта (`CLAUDE.md`, `AGENTS.md`). Ссылку на такой репозиторий можно добавить в список ниже через PR.
- **Локально**, если словарь для себя или для команды.

## Формат

Скопируйте `_template.md` и заполните. Обязательные поля frontmatter:

| Поле | Что писать |
|---|---|
| `name` | короткое имя латиницей, через дефис; используется в ID флагов `ext:<name>:...` |
| `description` | одна строка: какая ниша |
| `applies_when` | признаки текста, при которых словарь подключается: тема, жанр, характерные слова |
| `version` | SemVer |
| `author` | кто поддерживает |
| `evidence` | на чём основан словарь: корпус, опыт редактирования, внешний источник |

Таблицы (любая может отсутствовать):

- **Маркеры**: флагуются всегда, как `lex-1a`. ID: `ext:<name>:lex-1a`.
- **Кластерные маркеры**: флаг при двух и больше в абзаце, как `lex-2`. ID: `ext:<name>:lex-2`.
- **Шаблонные фразы ниши**: зачины, финалы, призывы. ID: `ext:<name>:template-phrases`.
- **Тезаурус**: термины, которые в нише законны. Снимают флаги базового словаря только в подходящем тексте.

## Ограничения

Расширение не может отключить P0-правила, правило `dash` и раздел «Никогда не добавлять при rewrite». Для расширений действуют те же требования, что и для правил: пример, где маркер срабатывает, и пример, где не должен (см. `../CONTRIBUTING.md`).
