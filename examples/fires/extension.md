# Подключаемый словарь: должно сработать

Тематические словари подключаются к скиллу как расширения. Флаги из них имеют вид `ext:<имя-словаря>:<правило>`. Словарь `example` ниже вымышлен и нужен только для того, чтобы показать формат: его правило `realty-cliche` ловит штампы объявлений о недвижимости. Скрипт `scripts/check.sh` не сверяет такие id с SKILL.md, их описывает сам словарь.

### ext-realty-ad
- profile: social
- expect: fires
- rules: [ext:example:realty-cliche, intensifiers]

> Уютная светлая квартира в шаговой доступности от метро! Развитая инфраструктура, тихий зелёный район. Действительно идеальный вариант для молодой семьи.

**Ожидание:**
- `ext:example:realty-cliche` (P1): «Уютная светлая квартира», «в шаговой доступности», «Развитая инфраструктура», «идеальный вариант для молодой семьи»
- `intensifiers` (P2): «Действительно»

Сколько минут до метро, какой этаж и площадь, объявление не говорит. При rewrite эти данные нельзя придумать.
