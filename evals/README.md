# Оценка переписывания

Протокол для проверки, улучшает ли новая версия скилла правку текстов. Построен по образцу протокола upstream (`evals/rewrite/protocol.json` в conorbronsdon/avoid-ai-writing) и упрощён под возможности одного мейнтейнера. Формальное описание в `protocol.json`.

## Как устроен прогон

1. **Отложенная выборка.** Тексты, на которых правила не писались и не настраивались. Перед прогоном файлы скилла и тексты замораживаются: их SHA-256 записывается в `SHA256SUMS`. После того как выходы прочитаны, кандидат не меняется. Если меняется, выборка становится выборкой разработки и для следующего решения нужны новые тексты.
2. **Эталонная разметка до прогона.** Разметчик, который не видел `SKILL.md`, отмечает для каждого текста тип исходника (A машинный, B смешанный, C живой), регистр, защищённые факты, авторские обороты и машинные фразы, которые должны уйти. Фразы буквальные, без регулярных выражений.
3. **Три условия:** предыдущая версия (baseline), новая версия (candidate) и простой промпт без скилла (simple). Простой промпт показывает, даёт ли скилл что-то сверх обычной просьбы.
4. **Несколько редакторов.** Каждое условие прогоняется на каждом тексте как минимум двумя моделями из разных семейств.
5. **Механические метрики** (`score.py`): потеря защищённого факта, потеря авторского оборота, оставшаяся машинная фраза, доля сохранённого текста, служебные пометки. Число символов тире считается для описания типографики, дефектом оно не считается.
6. **Слепое судейство.** Судья видит исходник и выходы всех условий одного редактора под случайными метками. Для каждого выхода он перечисляет потерянные факты, лишние правки живого текста, пропущенные машинные приметы, выдумки и ставит место. Шаблон задания для судьи: `judge-prompt.md`.
7. **Проверка человеком.** Носитель языка вслепую оценивает часть кейсов. Без этого результат считается предварительным.

## Правило решения

Записано заранее в `protocol.json`. Кандидат проходит, если у каждого редактора у него не больше потерь фактов, выдумок и лишних правок, чем у baseline и simple, и меньше пропущенных машинных примет, чем у baseline, хотя бы на одном типе исходника. Предпочтение судей описательное: им нельзя перекрыть потерю фактов.

## Запуск подсчёта

```bash
python3 -I evals/score.py cases.json texts/ runs/
```

`runs/` содержит папки `out-<редактор>-<условие>/` с файлами `<id>.md`. Ничего, кроме стандартной библиотеки Python 3, не нужно.

## Приватность

Реальные тексты для отложенной выборки могут содержать личные данные. Они в репозиторий не попадают. Публикуются протокол, скрипт, хеши и агрегированный отчёт в `reports/`.

## English summary

A held-out rewrite evaluation modeled on upstream's protocol: frozen skill files and texts, gold labels written blind to the skill, three conditions (baseline, candidate, simple prompt), at least two model families as editors, mechanical scoring (`score.py`) plus blind LLM judging and partial native-speaker review. The decision rule is fixed in `protocol.json` before the run. Private texts stay out of the repository; only aggregates are published.
